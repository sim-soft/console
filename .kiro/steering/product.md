# Product Overview

Simsoft Console is a PHP library that wraps Symfony Console to provide a
Laravel-inspired developer experience for building CLI applications.

## Key Value Proposition

- Simplifies Symfony Console's verbose API with opinionated conventions
- Supports both class-based commands and closure-based commands
- Provides built-in command locking (prevents parallel execution)
- Lazy-loads commands by default for performance
- Offers reusable traits for common CLI patterns (date ranges, file options)

## Target Users

PHP developers building CLI tools who want Symfony Console's power with less
boilerplate.
